## Question Tags

A **question tag** is a short clause added to the end of a statement to seek **confirmation, verification, or engagement**.

### 1. Formation

The tag generally mirrors the **auxiliary/tense and subject** of the main clause.

* *He is tired, **isn't he?***
* *He called me, **didn't he?***
* *Raju beats me, **doesn't he?***

### 2. Polarity Rule

| Main Clause     | Tag         |
| --------------- | ----------- |
| **Affirmative** | Negative    |
| **Negative**    | Affirmative |

* *You speak English, **don't you?***
* *You don't speak English, **do you?***

### 3. Negative Tags

Negative tags normally use a **contracted auxiliary + not**:

* don't, doesn't, didn't
* isn't, aren't, wasn't, weren't

### 4. Functions

* **Confirmation:** seek agreement.
* **Verification:** check whether information is correct.
* **Engagement:** invite the listener into the conversation.

> **Positive statement → negative tag; Negative statement → positive tag.**

## Question Formation

English question formation depends on **word order, tense, and subject–verb agreement**.

### 1. Sentence Structure

Basic English word order:

> **Subject + Verb + Object**

**Agreement** matches the verb with the subject according to **person and number**.

### 2. Forming Questions

In questions, the **auxiliary/tense marker is moved to the front**.

When no auxiliary is available, **do-support** is used:

* *Raju loves pizza.* → *What **does** Raju love?*
* *Raju loved pizza.* → *What **did** Raju love?*

The main verb returns to its **base form** after *do/does/did*.

### 3. Types of Questions

| Type                | Purpose                    | Example            |
| ------------------- | -------------------------- | ------------------ |
| **WH-question**     | Seeks specific information | What did Raju buy? |
| **Yes/No question** | Seeks confirmation         | Is Raju coming?    |

Common WH-words: **what, who, when, where, why, how**

### 4. Pragmatics

A grammatically correct question should also be **socially appropriate**. Questions should gather information without unnecessarily sounding aggressive or interrogative.

> **Question formation = front the auxiliary; use do/does/did when necessary.**

## Embedded Sentences and Questions

### 1. Complex Sentences

A **complex sentence** contains a main (matrix) clause and an **embedded/subordinate clause** functioning as an object or complement.

> *I wonder **what her name is**.*

The embedded clause can function as the **object of the matrix verb**.

**Complementizers** such as *that* can introduce embedded clauses:

* *I wish **that I had money**.*

### 2. Embedded Questions

A direct question uses **auxiliary/tense fronting**:

> *What **did** you eat?*

When embedded, **fronting does not occur**. The embedded clause follows normal declarative word order:

* *Correct: I asked what you ate.*
* *Incorrect: I asked what did you eat.*

### 3. Why?

An embedded question is **not an independent question**. It functions as part of the larger sentence, so it retains declarative word order.

### 4. Pragmatic Function

Embedded questions can make requests and queries **less direct and more polite**:

* *What is her name?* → *I wonder what her name is.*
* *Is the doctor available?* → *Could you tell me if the doctor is available?*

> **Direct question → fronting**
> **Embedded question → no fronting**

## Whether vs. If Clauses

**Whether** and **if** can introduce complement clauses, often forming **indirect questions**.

### 1. Complement Clauses

A complement clause functions as an object or complement of a verb.

> *I know **whether she will come**.*

They can make questions **less direct and more polite**.

### 2. Whether vs. If

| Context               | **Whether**            | **If**            |
| --------------------- | ---------------------- | ----------------- |
| Before infinitive     | **Required**           | Not possible      |
| After preposition     | **Preferred/required** | Generally avoided |
| Formal language       | Preferred              | Less formal       |
| Informal language     | Possible               | Common            |
| Offering alternatives | Possible               | Possible          |

Examples:

* *I don't know **whether to accept**.*
* *It depends on **whether she agrees**.*
* *I don't know **if she will come**.*

### 3. Usage Constraints

* Only certain verbs readily take these complement clauses, e.g. **ask, know, understand, decide**.
* Long or **heavy complement clauses** commonly occur toward the end of the sentence.

> **Whether = more flexible/formal; If = generally more informal.**
---

## That-Clauses

A **that-clause** is an embedded clause introduced by the complementizer **that**.

### 1. Embedded Clauses

A sentence becomes complex when an embedded clause functions within a larger sentence.

> *I wish **that I had money**.*

**That** can often be omitted in finite clauses:

* *I believe **that he is innocent**.*
* *I believe **he is innocent**.*

### 2. Finite vs. Non-Finite

| Type           | Characteristic                  | Example                            |
| -------------- | ------------------------------- | ---------------------------------- |
| **Finite**     | Contains tense                  | I believe that he **is** innocent. |
| **Non-finite** | No tense; often uses infinitive | I want **to go**.                  |

### 3. Functions of That-Clauses

* **Subject:** *That Mary forgot John was a shock.*
* **Object:** *I believe that he is innocent.*
* Can occur as the direct object alongside an indirect object:

  * *She told **me** **that she was leaving**.*

### 4. Key Concepts

* **Recursion:** embedding a clause within another embedded clause.
* **Heavy object:** a long that-clause functioning as an object, typically placed toward the end.
* **Complementizer:** *that* introduces the embedded finite clause.

> **That-clause = an embedded finite clause introduced by “that”.**
